Après l’export

Mettre vos projets en ligne.

  1. Décompressez l’archive ZIP sur votre ordinateur. Elle contient content/projects.json et uniquement les nouvelles photographies ajoutées.
  2. Ouvrez la branche de publication sur GitHub. Avec « Add file » puis « Upload files », déposez les dossiers extraits content et, s’il est présent, assets à la racine de la branche gh-pages, en conservant leur organisation.
  3. Validez avec « Commit changes ». Après le déploiement GitHub Pages, actualisez le site public et vérifiez les pages de vos projets. Conservez l’archive comme sauvegarde.

Les photographies déjà présentes sur le site restent à leur emplacement et ne sont pas recopiées dans l’archive. Importer un JSON permet de reprendre des textes ; les images qu’il référence doivent déjà exister sur le site ou être ajoutées séparément.
